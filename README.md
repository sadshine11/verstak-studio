# ВЕРСТАК — сайт веб-студии

Многостраничный сайт студии проектирования и разработки: услуги со сметой,
индекс работ с разборами проектов, калькулятор предварительной сметы и бриф.

**Демо:** https://sadshine11.github.io/verstak-studio/

---

## Что внутри

| Страница | Адрес | Содержание |
| --- | --- | --- |
| Главная | `/` | производственный лист студии, услуги, индекс работ, процесс, калькулятор сметы, доказательства, бриф |
| Работы | `/works` | все проекты с фильтром по типу и схемами экранов |
| Разбор проекта | `/works/armastal`, `/works/klinika-sever`, `/works/dom-17` | задача, ограничения, решения, состав работ, результат |
| Студия | `/studio` | принципы, команда, процесс по неделям, ставка и оплата, вопросы |
| Контакты | `/contact` | бриф с проверкой полей, реквизиты, когда студия отказывается от проекта |
| 404 | любой другой адрес | подсказки, куда идти |

## Решения, которые стоит знать при доработке

- **Дизайн-система** — один файл `src/styles/global.css`: токены цвета, типографика,
  сетка, кнопки, формы, таблицы. Цвет бренда меняется в `:root` — `--accent`.
- **Контент отделён от вёрстки**: `src/data/studio.ts` (услуги, работы, команда,
  процесс, вопросы) и `src/data/cases.ts` (разборы проектов). Правка текста не
  трогает разметку.
- **Шрифты свои**, в `public/fonts` — Golos Text, JetBrains Mono и Source Serif
  (только кириллица и латиница, ~130 КБ на все начертания). Внешних запросов нет.
- **Схемы экранов проектов** (`src/components/WorkPreview.astro`) — векторные,
  рисуются кодом. Когда появятся реальные скриншоты, компонент заменяется на `<img>`.
- **Калькулятор сметы** (`src/components/Estimator.astro`) считает по часам и
  разделам: ставка `RATE`, нормативы по типам проектов — в начале скрипта компонента.
  Кнопка «Отправить смету в бриф» переносит расчёт в форму (и в `sessionStorage`,
  если бриф на другой странице).
- **Доступность**: пропуск к содержанию, видимый фокус, формы с `aria-invalid` и
  текстом ошибок, контраст мелкого текста не ниже 4.5:1, `prefers-reduced-motion`
  отключает появление блоков.
- **JS только там, где нужен**: часы студии, мобильное меню, фильтр работ,
  калькулятор, проверка брифа. Всё остальное — статика.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # просмотр собранного
```

Превью для соцсетей пересобирается отдельно:

```bash
npm i -D @resvg/resvg-js && node scripts/make-og.mjs
```

## Публикация

Push в `main` запускает `.github/workflows/deploy.yml`: сборка с
`BASE_PATH=/verstak-studio/` и деплой на GitHub Pages. Вручную —
`gh workflow run deploy.yml`.

Для своего домена: убрать `BASE_PATH` из workflow (база станет `/`) и заменить
`site` в `astro.config.mjs`.

## Демонстрационная версия

Названия клиентов, цифры, отзывы, состав команды и контакты — вымышленные:
это витрина возможностей, а не данные существующей компании. Перед реальным
запуском:

1. Заменить контент в `src/data/studio.ts` и `src/data/cases.ts`.
2. Подставить настоящие реквизиты и контакты (`studio` в `src/data/studio.ts`).
3. Подключить отправку брифа (сейчас форма показывает результат и письмо-заготовку —
   см. обработчик `submit` в `src/components/BriefForm.astro`).
4. Убрать `<meta name="robots" content="noindex, nofollow">` в `src/layouts/Base.astro`
   и запрет обхода в `public/robots.txt`.
5. Убрать строку «Демонстрационная версия» в подвале (`src/components/Footer.astro`).
